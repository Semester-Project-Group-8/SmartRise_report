In technical writing, adhering to a standardized referencing style ensures consistency, accuracy, and professionalism. \vspace{0.5cm} \textbf{What to Include:} \begin{itemize} \item Research papers, journal articles, or books referenced during the project \item Online resources such as technical blogs, official documentation, or standards \item Any tools, libraries, or datasets that are cited \end{itemize} The \textbf{IEEE} style is commonly used in technical and engineering fields. It is a \textbf{numeric citation style} where references are numbered in the order they are cited in the text. \vspace{0.5cm} \textbf{Key Features of IEEE Style:} \begin{enumerate} \item \textbf{In-Text Citations} \begin{itemize} \item Use numbers in square brackets to cite sources, e.g., ``As described in [1]...'' \item The numbers correspond to the order of citation, not alphabetical order \end{itemize} \item \textbf{Reference List Format} \begin{itemize} \item The references are listed at the end of the document, numbered in the same order as they appear in the text. \item Each reference follows a specific format depending on the type of source. \end{itemize} \item \textbf{Common Formats in IEEE Style} \begin{itemize} \item Book: [1] Author(s), \textit{Title}, Edition (if applicable). City: Publisher, Year. \begin{itemize} \item Example: [1] A. B. Smith and C. D. Jones, \textit{Introduction to Embedded Systems}, 3rd ed. New York: Springer, 2018. \end{itemize} \item Journal Article: [2] Author(s), ``Title of article,'' Journal Name, vol. X, no. Y, pp. ZZZ--ZZZ, Month Year. \begin{itemize} \item Example: [2] J. K. Doe, ``An efficient algorithm for data compression,'' IEEE Transactions on Computers, vol. 67, no. 3, pp. 456--468, Mar. 2022. \end{itemize} \item Conference Paper: [3] Author(s), ``Title of paper,'' in Proceedings of the Conference Name, Location, Year, pp. ZZZ--ZZZ. \begin{itemize} \item Example: [3] K. L. Brown, ``Innovations in autonomous systems,'' in Proceedings of the 15th International Conference on Robotics, Tokyo, Japan, 2021, pp. 34--45. \end{itemize} \item Website: [4] Author(s) (if available), ``Title of web page,'' Website Name, Date of publication. [Online]. Available: URL \begin{itemize} \item Example: [4] T. Nguyen, ``Understanding neural networks,'' AI Research Blog, Jan. 2023. [Online]. Available: https://www.aiblog.com/neural-networks \end{itemize} \end{itemize} \end{enumerate} Microsoft \textbf{Word} has built-in tools for managing references and citations, and it supports several citation styles, including IEEE.
